# Inkora — Free Online Notepad

A modern, colorful browser notepad to **write, auto-save, search, open, and download** notes as TXT — no signup, no install.

**Live demo:** [https://imranbru99.github.io/smart-notepad/](https://imranbru99.github.io/smart-notepad/)

---

## Features

- Free online notepad & text editor in the browser
- Auto-save to local storage (private on your device)
- Multi-tab notes with pin, duplicate, and delete
- Open `.txt` / `.md` files · Download as `.txt` or `.md`
- Find & replace · Search across all notes
- Markdown preview · Focus / zen mode
- Voice typing (speech-to-text where supported)
- Copy, print, share, case transforms, insert date & time
- 5 themes: **Blizzard** (default), Aurora, Sunset, Forest, Citrus
- Reading time & live word / character / line counts
- SEO-ready meta tags + schema for “free online notepad”

## Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + N` | New note |
| `Ctrl + O` | Open file |
| `Ctrl + S` | Download as TXT |
| `Ctrl + F` | Find & replace |
| `Ctrl + Shift + F` | Focus mode |
| `Esc` | Exit focus / close find |

## Quick start

1. Clone or download this repository
2. Open `index.html` in any modern browser  
   — or visit the [live site](https://imranbru99.github.io/smart-notepad/)
3. Start writing; notes save automatically

```bash
git clone https://github.com/imranbru99/smart-notepad.git
cd smart-notepad
# open index.html in your browser
```

## Tech

- Single-page app: HTML, CSS, vanilla JavaScript
- Persistence: `localStorage`
- No build step, no dependencies

## Privacy

Notes stay in **your browser’s local storage** on this device. They are not uploaded by the app itself. Clearing site data will remove saved notes.
